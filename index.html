What a shopper actually sees

The ranking above is measured through the APIs. We re-ran 12 of the questions by hand in the consumer apps to see how far it carries.

37%
of the brands an assistant names consistently through its API also appear in one app answer
75%
is what a single API run manages against the same test, so the difference is the app, not chance
6
of 36 app answers named no brand at all, asking a question back instead. No API run ever did

Read the ranking as what the models put forward, not as what every shopper receives. The apps name fewer brands than the models behind them, and they differ from each other: ChatGPT 52%, Gemini 37%, Perplexity 27%.

No brand names in the questions

The 76 questions behind this ranking mention no brand at all. Every name in the ranking is one the assistants chose themselves.

Asked five times each

Each question was asked 5 times in a fresh session. A brand counts only if it appeared in at least 3 of those 5.

Careful with ‘missing’

A brand is called missing only if it stayed missing across all 3 assistants. We count those brands but never name them.

You can check it

Every number traces back to a saved answer. We will re-run any part of this on request and publish how closely the second run matches.

How this was measured

Questions
100 shopper questions, half in English and half in Gulf Arabic, written from 8,102 real shopper posts, comments and searches. None copied word for word.
Assistants
Gemini gemini-3.5-flash, ChatGPT gpt-5.6-terra and Perplexity sonar, each with live web search, asked from a blank slate every time.
Collected
2026-08-13 to 2026-08-16. AI answers change over time, so this is a dated snapshot, not a permanent scoreboard.
Cross-check
12 questions re-run by hand in the consumer apps. See the panel above.
Full method
Published in full, including how questions were built and how brands are counted.
